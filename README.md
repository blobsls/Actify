# Actify

**Actify** is a lightweight, declarative JavaScript UI library inspired by React. It empowers developers to build fast, modular, and reactive interfaces using a familiar component-based architecture—without the bloat.

## 🚀 Why Actify?

- ⚡ Tiny footprint
- 🧠 Simple virtual DOM
- 🎯 Declarative component API
- 🔁 Built-in state management (like `useState`)
- ⚙️ No build tools required (can run in the browser)
- 📦 Ideal for learning, rapid prototyping, or creating your own React-like library
